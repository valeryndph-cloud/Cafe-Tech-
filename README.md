# ☕ CaféTech

## 📌 Descripción del proyecto

**CaféTech** es una landing page moderna diseñada para un concepto innovador que fusiona el mundo del café de especialidad con espacios de trabajo y tecnología.

La página presenta un espacio pensado para estudiantes, emprendedores y amantes de la tecnología, donde pueden disfrutar de un buen café mientras estudian, trabajan, comparten ideas y desarrollan nuevos proyectos.

---

## ✨ Características principales

* **Diseño Responsive:** Adaptable a dispositivos móviles, tablets y computadores mediante CSS Flexbox y Media Queries.

* **Navegación Fluida:** Menú superior fijo (`sticky`) con desplazamiento suave (`smooth scroll`) hacia cada sección de la página.

* **Diseño Interactivo:** Efectos de transición, animaciones al pasar el cursor (`hover`), sombras y botones interactivos.

* **Diseño Visual:** Uso de imágenes de fondo, gradientes y una paleta de colores inspirada en el café.

---

## 📱 Secciones de la página

La landing page cuenta con las siguientes secciones:

* 🏠 **Inicio:** Pantalla principal de bienvenida con una imagen de fondo, presentación de CaféTech y un botón de llamada a la acción.

* ☕ **Servicios:** Tarjetas interactivas que presentan los principales servicios: café especial, zona de trabajo y conexión WiFi.

* 👥 **Nosotros:** Información sobre la propuesta de valor de CaféTech y el público al que está dirigido.

* 📊 **Estadísticas:** Indicadores representativos sobre clientes, tipos de café y la experiencia del espacio.

* 📞 **Contacto:** Información de ubicación, teléfono, correo electrónico y redes sociales.

---

## 🛠️ Tecnologías utilizadas

Para el desarrollo de este proyecto se utilizaron las siguientes tecnologías:

* **HTML5:** Para crear la estructura semántica de la página.
* **CSS3:** Para los estilos, colores, diseño responsive, transiciones, sombras y efectos visuales.
* **Git:** Para el control de versiones del proyecto.
* **GitHub:** Para el trabajo colaborativo mediante ramas y el alojamiento del repositorio.
* **GitHub Pages:** Para la publicación de la landing page.
* **Unsplash:** Para utilizar imágenes externas de alta calidad.

---

## 🚀 Instalación y uso

Para utilizar el proyecto, sigue estos pasos:

1. Clona el repositorio o descarga los archivos del proyecto.
2. Abre la carpeta del proyecto en Visual Studio Code o en tu editor de código preferido.
3. Asegúrate de tener un navegador web moderno, como Google Chrome, Mozilla Firefox o Microsoft Edge.
4. Abre el archivo `index.html` en el navegador.
5. Explora las diferentes secciones de la landing page mediante el menú de navegación.

## 👥 Trabajo en equipo

Este proyecto fue desarrollado de forma colaborativa utilizando **Git y GitHub**.

Cada integrante del equipo puede trabajar en una rama diferente para desarrollar una sección específica de la landing page y posteriormente integrar los cambios en la rama principal (`main`).

Ramas del proyecto:

* `seccion-inicio`
* `seccion-servicios`
* `seccion-contacto`
